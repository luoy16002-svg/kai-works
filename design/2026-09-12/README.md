# Selected work index

The final home page is a compact index of three usable tools. Real interfaces occupy the main view: a filterable CSV preview, an interactive original GLB, and the recorded results of a runnable Python demo. There is no large promotional hero.

The image studies in this directory explored the complete pages with short prompts and room for independent visual choices. `round-3/index1.png` informed the final three-column composition and quiet palette. The implemented interface is React, CSS and WebGL; these generated studies are not application screenshots or functional surfaces.

The final implementation includes:

- All-project and focused layouts, with width interpolation and keyboard-accessible controls.
- A model transition with preserved framing, interpolation and resource cleanup.
- Route preloading and shared project-to-workspace View Transitions, with normal navigation when unsupported.
- Reduced-motion handling and demand-driven model rendering.
- A compact desktop layout and one-project tabs for smaller screens.
- CSV column matching and explicit local dataset persistence, with transaction tests.
- Actual model material properties, exposure adjustment, local import and PNG export.

`public/work/current.png` and `public/work/halo.png` are screenshots of the running tools. `verification/work-index-2026-09-12.png` is the actual home page. The browser verification record describes what was checked and retains the exported CSV and model PNG.
