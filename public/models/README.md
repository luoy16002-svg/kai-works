# HALO sample objects

Two original objects made for the [model workspace](https://luoy16002-svg.github.io/kai-works/#/halo/models):

- **Arc** — a table light with a brass stem, green enamel shade and opal diffuser.
- **Fold** — a fluted terracotta vessel with a hollow interior and an unglazed foot.

These are self-contained, uncompressed glTF 2.0 binary files. Their materials are embedded and neither file needs a network request for textures. They have no animations.

Rebuild both files from the repository root with `node scripts/build-model-samples.mjs`. The source geometry and materials are defined in that script; no third-party model assets are used.
